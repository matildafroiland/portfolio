# matildafroiland.no

My UX portfolio. Plain HTML, CSS and JavaScript, no build step.

- `index.html` – home page (projects, about, contact)
- `vaersikret.html`, `timebox.html` – case studies
- `img/`, `cs/`, `app/` – images and video
- `fonts/` – self-hosted fonts (Fraunces, Reenie Beanie, DM Sans; SIL Open Font License)
- `models/` – Timebox 3D parts used in the scroll animation

To add the CV: put `cv.pdf` in this folder and remove `hidden` from the "Download my CV" link in `index.html`.
